# Week 01 - JavaScript Assignments

This folder contains a collection of JavaScript practice assignments focused on array methods, object manipulation, and real-world coding scenarios.

## 📚 Assignments Overview

| File | Topic | Focus |
|------|-------|-------|
| **E-Commerce.js** | Shopping Cart Summary | `filter()`, `map()`, `reduce()`, `find()`, `findIndex()` |
| **Application-Setting-Controller.js** | User Settings Management | Object manipulation, conditional logic |
| **Bank-Transaction.js** | Transaction Analyzer | Array filtering, mapping, reducing |
| **Course-Price-Tag-Labeler.js** | Course Pricing | Data transformation and labeling |
| **Daily-Temperature.js** | Temperature Tracking | Array operations on numeric data |
| **Employee-Payroll-Processor.js** | Payroll Calculations | Complex object processing |
| **Enrollment-Eligibility.js** | Student Enrollment | Conditional logic and filtering |
| **Exam-Result-Summary.js** | Result Analysis | Data aggregation and reporting |
| **Movie-Streaming-Platform.js** | Streaming Service Logic | Array and object management |
| **Online-Course-Name-Processor.js** | Course Name Processing | String and data manipulation |
| **Profile-Manager.js** | User Profile Management | CRUD operations on objects |
| **Smart-Login-Status-Engine.js** | Login Status Logic | State management |
| **Student-Marks-List.js** | Mark Tracking | Array operations on student data |
| **Student-Performance-Dashboard.js** | Performance Metrics | Data analysis and aggregation |
| **User-Profile-Manager.js** | User Data Management | Object operations |

## 🎯 Key Concepts Covered

- **Array Methods**: `filter()`, `map()`, `reduce()`, `find()`, `findIndex()`
- **Object Manipulation**: Property access, modification, freezing
- **Data Transformation**: Converting and restructuring data
- **Conditional Logic**: Ternary operators, if-else conditions
- **Real-world Scenarios**: E-commerce, banking, education, payroll

## 🚀 How to Use

1. Open any `.js` file to view the assignment
2. Each file contains:
   - Problem description and scenario
   - Test data
   - Tasks to complete
   - Starting code
3. Implement the required tasks for each assignment
4. Test your solutions using Node.js:
   ```bash
   node filename.js
   ```

## 💡 Learning Path

Start with basic assignments and progress to more complex scenarios:
1. Begin with simpler object manipulation (Application-Setting-Controller)
2. Move to array methods fundamentals (E-Commerce, Bank-Transaction)
3. Progress to complex data processing scenarios
4. Tackle full real-world system logic (Dashboard, Profile Manager)

## 📝 Notes

- All files are JavaScript and can be run in Node.js
- Each assignment includes test data to work with
- Focus on understanding array methods and their practical applications
- Practice data transformation patterns for real-world applications
