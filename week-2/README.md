# Week 02 - JavaScript Projects

This repository contains JavaScript projects and utilities covering various programming concepts and applications.

## 📁 Project Structure

### Standalone Utilities
- **class.js** - JavaScript class implementation examples and patterns
- **date.js** - Date manipulation and handling utilities
- **shallow & deep copy.js** - Object and array copying techniques

### E-Commerce Shopping Cart
Located in `e-commerce shopping cart/`
- **app.js** - Main application entry point
- **cart.js** - Shopping cart logic and management
- **product.js** - Product data and operations
- **discount.js** - Discount calculation and application
- **payment.js** - Payment processing logic

### Master Project Collection
Located in `master project collection/`
- **user-engine.js** - User management system
- **role-engine.js** - Role and permissions system
- **cart-engine.js** - Shopping cart engine
- **course-engine.js** - Course management engine

### Task Management
Located in `task management/`
- **app.js** - Task management application
- **task.js** - Task operations and logic
- **validator.js** - Input validation utilities

## 🚀 Getting Started

Each project can be run individually:

```bash
# Run individual files
node class.js
node date.js

# Run projects with entry points
node "e-commerce shopping cart/app.js"
node "task management/app.js"
```

## 📝 Notes

- All files are JavaScript (.js) based
- Each project demonstrates different programming patterns and concepts
- Modular structure allows for reusable components

## 🔧 Requirements

- Node.js (any recent version)
- No external dependencies required
