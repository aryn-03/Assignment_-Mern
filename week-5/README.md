### Backend development

1. Create git repo
    git init
2. Add .gitignore file
3. Create .env file for environment variables & Read data from .env with "dotenv" (npm install dotenv)
4. Generate package.json
5. Create express app
6. Connect to database
7. Add middlewares(body parser, err handling middlewares)
8. Design Schema and create models
9. Design REST APIs for all resources
